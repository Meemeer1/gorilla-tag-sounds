# Gorilla Tag Soundboard Sounds

219 `.ogg` sound files for use with the NXO / Seralyth-style Lua soundboard.

## Use with the soundboard
Point the menu''s `SOUNDBOARD_CONFIG` at this repo:

    owner  = "Meemeer1"
    repo   = "gorilla-tag-sounds"
    branch = "main"
    folder = "sounds"

All files live in `sounds/`. The soundboard only supports `.mp3`, `.wav`, and `.ogg`.
